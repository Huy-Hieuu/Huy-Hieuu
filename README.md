## 🚀 About Me

I'm a **Senior AI Engineer** at **[MoMo](https://www.momo.vn/)**, Vietnam's largest digital wallet, on the **Business AI / Credit Tech** team. I design and ship the AI systems behind consumer lending — from data pipelines and decision models to LLM agents running in production under real latency, cost, and compliance constraints.

My work sits where **agent architecture**, **ML engineering**, and **distributed systems** meet. I care about the unglamorous part of AI: making systems reliable, measurable, and cheap enough to run every day — not just impressive in a demo.

- 🏦 Building AI for **fintech & consumer lending** at scale
- 🤖 Designing **LLM agents** with memory, evaluation, and self-improvement loops
- 🎙️ Shipping **real-time voice agents** with low-latency speech pipelines
- 📍 Based in **Ho Chi Minh City, Vietnam** 🇻🇳

## 🛠️ Selected Work

### 🔁 Agent Optimizer — a meta-agent that improves other agents
Designed a meta-agent that analyzes graph-based LLM agents, proposes changes, and evaluates them in a closed loop (setup → optimization → human-approved exit). Turns agent tuning from manual prompt-tweaking into a repeatable, auditable engineering process.

![LangGraph](https://img.shields.io/badge/LangGraph-1C3C3C?style=flat-square&logo=langchain&logoColor=white) ![Agent Eval](https://img.shields.io/badge/Agent_Evaluation-6C63FF?style=flat-square) ![Self-Improving](https://img.shields.io/badge/Self--Improving_AI-8E44AD?style=flat-square)

### 🧠 Hierarchical Memory for Multi-Agent Systems
Architected a tree-structured memory layer with typed nodes (episodic, semantic, goal, topic, file) and LLM-based retrieval routing, so agents recall the *right* context instead of the *most similar* context. Includes an explorer UI for inspecting and debugging agent memory.

![Agent Memory](https://img.shields.io/badge/Agent_Memory-2E86C1?style=flat-square) ![RAG](https://img.shields.io/badge/RAG-117A65?style=flat-square) ![Retrieval Routing](https://img.shields.io/badge/Retrieval_Routing-CA6F1E?style=flat-square)

### 🎙️ Real-Time Voice Agent Infrastructure
Building speech-to-speech agents across cascaded (ASR → LLM → TTS) and end-to-end pipelines, focused on conversational latency, voice-activity detection, and natural barge-in handling.

![Pipecat](https://img.shields.io/badge/Pipecat-FF6F61?style=flat-square) ![LiveKit](https://img.shields.io/badge/LiveKit-1F1F1F?style=flat-square&logo=livekit&logoColor=white) ![Low Latency](https://img.shields.io/badge/Low_Latency-E74C3C?style=flat-square)

### 💳 AI & Data Platform for Consumer Lending
Engineered core components of MoMo's lending stack, including a data abstraction layer that unifies feature access across credit products, feeding underwriting and decisioning models serving [X]M+ users.

>
> ⏱️ **Latency and cost are features.** If it's too slow or too expensive to run daily, it doesn't ship.
